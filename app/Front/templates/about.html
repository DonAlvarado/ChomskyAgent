Acerca de ChomskyAgent

ChomskyAgent es una herramienta web diseñada para analizar, clasificar y visualizar gramáticas formales y autómatas dentro de la Jerarquía de Chomsky. Incluye un agente explicativo, un modo tutor interactivo y la capacidad de generar reportes PDF.

El proyecto combina:

  • Python (Flask) para la API
  • TailwindCSS para la interfaz moderna
  • Graphviz para diagramas
  • Módulos propios para análisis formal
  • IA explicativa local (Reasoner + NLP)
